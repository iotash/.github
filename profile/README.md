## iota

An agent CLI for the terminal, written in Rust. You configure agents — a model,
a prompt, a set of tools — and run them.

```bash
cargo install --git https://github.com/iotash/iota
iota config init
iota run <agent>
```

Docs and the rest of the story: [iota.sh](https://iota.sh).

- [iota](https://github.com/iotash/iota) — the CLI
